# Audophile SCSS
This project is a simple page fully made with SCSS, to implement the [Audophile Design from Front End Mentor.](https://www.frontendmentor.io/challenges/audiophile-ecommerce-website-C8cuSd_wx)

# What does the project represent?
The project was mainly a challenge to implement a properly responsive, yet semantically correct
The project features:
- Several design components that can be reused freely.
- Fully responsive web-page for Desktop, Tablet and Mobile.
- A bash file to sit down and work on the project easier.
- Properly organized SCSS source code.
- Accurate 1:1 recreation of the Figma design.

# How to run the project?
If you want to locally run the project and mess with it, clone the project:
```bash
# Clone with SSH
git clone git@github.com:nikoloz-code23/audophile-scss.git
# Or clone with HTTPS
git clone https://github.com/nikoloz-code23/audophile-scss.git
```
And run it the following way:
```bash
# If on Linux/WSL
./hotreload.sh
```
And if you are on Windows:
1. Input the filepath of the project inside `/src/scss/variables/path.scss`.
2. Run the following command: `sass --watch ./src/scss/main.scss ./src/styles/styles.css` in PowerShell or Windows Terminal.
